PROJECT OVERVIEW

Audio-Visual Integrity Detector

A.V.I.D. is a media-analysis interface designed to help inspect potential inconsistencies across visual and audio signals and organize findings for review.

CORE WORKFLOW
Input → Analysis → Evidence → Report
Modular design prepared for backend integration.

Backend integration
Designed to connect with the model pipeline later.

The interface separates media selection, analysis state, result rendering and report export. When the backend is available, the sample analysis function can be replaced with a request to your inference endpoint. The response should provide a verdict, scores, timestamps, signal type and evidence descriptions.

Important: Results come from the PIA research model. It can be wrong on videos unlike its training data, so treat the output as a signal, not proof.
